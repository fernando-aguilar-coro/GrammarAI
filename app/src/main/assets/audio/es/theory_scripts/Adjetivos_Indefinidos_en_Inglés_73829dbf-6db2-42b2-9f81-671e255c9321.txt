¡Hola! Hoy vamos a aprender a hablar de cantidades sin necesidad de usar números exactos. Para esto, usamos los adjetivos indefinidos: a lot of, some y any. Es muy sencillo si sigues estas reglas básicas.

Empecemos con a lot of, que significa mucho o muchos. Lo usamos principalmente en oraciones afirmativas para indicar una cantidad grande, y lo mejor es que funciona tanto para cosas contables, como amigos, como para incontables, como el agua. Por ejemplo, puedes decir I have a lot of friends, que se pronuncia ai jav a lot of frends, o We drink a lot of water, que suena como ui drink a lot of uoter.

Ahora, pasemos a some, que significa algo de o algunos. Este también se usa en oraciones afirmativas para cantidades moderadas. Por ejemplo, I need some apples, que significa necesito algunas manzanas, o She wants some milk, ella quiere algo de leche. Ojo aquí, hay una excepción importante: usamos some en preguntas cuando estamos ofreciendo algo o pidiendo algo de forma educada. Por ejemplo, si quieres ofrecer té, dirías Would you like some tea?

Finalmente, tenemos a any, que significa algún, ninguno o nada de. Este es el compañero inseparable de las oraciones negativas y de las preguntas. Si quieres preguntar si alguien tiene hermanos, dirías Do you have any brothers? Y si quieres decir que no tienes dinero, dirías I don't have any money. Recuerda que any es obligatorio en estos casos.

Para que no cometas errores comunes, ten en cuenta dos cosas. Primero, nunca uses some en oraciones negativas. Si quieres decir que no necesitas ayuda, lo correcto es decir I don't need any help, nunca uses some ahí. Segundo, aunque existen palabras como much o many, en el inglés hablado cotidiano, cuando quieras decir mucho en una oración afirmativa, prefiere siempre a lot of. Por ejemplo, di I have a lot of money en lugar de I have many money.

Resumiendo, usa a lot of para afirmaciones con cantidades grandes, some para afirmaciones o peticiones amables, y deja any exclusivamente para tus preguntas y tus negaciones. ¡Practícalo y verás qué rápido lo dominas!
