¡Hola! Hoy vamos a aprender cómo decir que algo existe en inglés. En español usamos la palabra hay para todo, pero en inglés debemos elegir entre dos opciones dependiendo de qué estemos hablando: There is o There are.

Empecemos con There is. Lo usamos para una sola unidad o para sustantivos incontables, como líquidos o conceptos que no podemos contar, por ejemplo, agua, dinero o tiempo. Se pronuncia der is. Por ejemplo, si quieres decir hay un banco cerca, dices There is a bank near here. Si quieres hablar de algo incontable, como la leche en la nevera, dices There is some milk in the fridge. La forma negativa es There isn't, y para preguntar, simplemente invertimos el orden: Is there a wifi connection?

Ahora, pasemos a There are, que se pronuncia der ar. Este lo usamos exclusivamente para plurales, es decir, cuando hay dos o más elementos. Por ejemplo, There are four people in the room, que significa hay cuatro personas en la habitación. En negativo usamos There aren't, y en pregunta, Are there any windows open?

Para hablar de cantidades sin ser exactos, usamos dos palabras clave: Some y Any. Some lo usamos en oraciones afirmativas, tanto para incontables como para plurales. Por ejemplo, There are some birds. Una excepción importante es que usamos some en preguntas cuando estamos ofreciendo o pidiendo algo, como en Would you like some water?

Por otro lado, Any lo usamos en oraciones negativas y en preguntas generales. En negativo, significa que no hay nada de algo, como en There isn't any salt. Y en preguntas, sirve para consultar si existe algo, como en Are there any chairs?

Para cerrar, ten en cuenta estos consejos de oro. Primero, nunca uses el verbo tener para decir que algo existe; usa siempre there is o there are. Segundo, si tienes una lista de cosas, el verbo debe concordar con el primer elemento; por eso decimos There is a sofa and two chairs, porque sofá es singular. Tercero, recuerda que en las respuestas cortas afirmativas nunca debemos contraer, así que siempre di Yes, there is. Y finalmente, ten cuidado con los incontables como advice, que significa consejo; en inglés no se puede contar, así que siempre diremos There is some advice.

¡Sigue practicando y verás qué fácil es dominar estas estructuras!
